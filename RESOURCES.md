# Product Thinking Resources

## Knowledge

- [IDG: Product Thinking learning pathway (AI Build 301)](https://www.idg.gov.sg/product-thinking/)
  The anchor source. Seven short modules from Singapore's Institute of Digital Government. Use for: the course's spine and terminology.
- [IDG Module 1: Understanding the Problem](https://www.idg.gov.sg/guides-and-resources/productthinking1/)
  "Great digital products start with problems, not solutions." Three principles: focus on the problem, chase outcomes, integrate policy/ops/tech. Use for: framing and motivation.
- [IDG Module 2: Start With The Whys](https://www.idg.gov.sg/guides-and-resources/productthinking2/)
  Five Whys, going from symptom to cause. Pick a cause that is within your team's control *and* close to the outcome. Use for: root cause lessons.
- [IDG Module 3: Craft a Clear Problem Statement](https://www.idg.gov.sg/guides-and-resources/productthinking3/)
  4Cs: Clarity, Consequence, Cause, Confirmation. The worked example (repeated form-filling across government services) is only in an image, so the details aren't in text form. Use for: problem statements.
- [IDG Module 4: Metrics](https://www.idg.gov.sg/guides-and-resources/productthinking4/)
  SMART, leading vs lagging indicators, Value-Cost Ratio (VCR). "Not all public-sector value can or should be expressed in dollars." Use for: outcome measurement.
- [IDG Module 5: Assumptions and Risks](https://www.idg.gov.sg/guides-and-resources/productthinking5/)
  Market / technical / team risk. Stages: proof of concept, proof of value, scale, maturity. Case study: the health appointment booking system started as a FormSG form feeding Excel. Use for: de-risking, staged delivery.
- [IDG Module 6: A Good Customer Experience](https://www.idg.gov.sg/guides-and-resources/productthinking6/)
  The 11-star framework; ParkingSG and RedeemSG as examples. Use for: CX and trade-offs.
- [IDG Module 7: Key Takeaways](https://www.idg.gov.sg/guides-and-resources/productthinking7/)
  Three mindset shifts: solutions → problems, outputs → outcomes, big-bang → staged delivery. Use for: review and spaced retrieval.
